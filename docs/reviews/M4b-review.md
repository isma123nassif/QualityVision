### Focus questions answered
- **Can `Auto` throw instead of falling back?** Only if the CPU fallback itself fails (bad `CpuModelPath`; the validator prevents this at start-up) or if a native fault aborts the process. Every managed exception from the CUDA attempt is caught at `YoloObjectDetector.cs:75`. The packaging-failure case (CPU-only build: "CUDA EP not enabled in this build") also throws a managed exception and falls back. That is why #1 is needed: the fallback hides the regression.
- **Thread-safety:** unchanged. `ActiveDevice` and `ActiveModel` are get-only and set in the constructor. `PipelineMetrics.Device/Model` use `Volatile` (`PipelineMetrics.cs:61-71`); writing the two fields separately is harmless because they are set once. The `_gate` lock, pinning, `WarmUp` and `Dispose`-under-lock are untouched.
- **Options validation:** matches the contract (both files always required, `GpuId >= 0`, enum check). See #10.
- **Architecture:** Core is untouched. `DetectionDevice`, the CUDA types and `IOptionsMonitor` stay in Infrastructure. CPM is respected (no `Version=` in any csproj). Log templates are structured. UI text is German and code is English.

Positives:
- The provider choice is contained in one constructor with a clear `switch`. The `Auto` fallback resets the load timer (`YoloObjectDetector.cs:81`), so the logged time is accurate. The "requested vs active" device appears in a single structured log line.
- `Ctor_AutoWithUnusableGpuModel_FallsBackToCpuAndLogsWarning` uses a corrupt model to make the fallback path deterministic on **any** machine, including asserting the warning. The existing integration tests are pinned to `Device=Cpu`, so they are hardware-independent, not weakened.
- The badge uses the text label as the primary signal and colour only as a reinforcement, with dark text on green/amber, so it is readable over Meet.

Verdict: **APPROVE**. There are no BLOCKERs and no failing gate reported. Fix MAJOR #1 (the guard test) and #2 (ADR-004 accuracy about `ExcludeAssets` per project) before the M4b commit. Note the MINOR items or defer them.
