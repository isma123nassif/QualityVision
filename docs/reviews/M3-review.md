### Focus questions answered
- **Pinning / InstallPixels lifetime: no use-after-free.** In `Detect`, the bitmap is disposed before the pin (`using` in reverse order, YoloObjectDetector.cs:75-77), all inside the lock. `DrawFrame` disposes image → pixmap → pin (SkiaFrameRenderer.cs:126-130). The raster canvas draws immediately, and `SKImage.FromPixels` / `InstallPixels` are created without release procs, so Skia holds no reference after the call. This only stays safe while the surface is a **CPU raster** surface. A GPU surface or `SKPictureRecorder` would defer the draw (the comment at :124-125 says so; keep it). `RunObjectDetection` returns value-type `SKRectI`s. The reviewer could not inspect YoloDotNet internals for cached input references, but the integration tests that dispose the frame right after `Detect` will catch a regression.
- **Disposal:** every Skia object is in a `using` (surface, fonts, paints, snapshot, `SKData`, pixmap, image, bitmap). The canvas is correctly not disposed. The typeface is loaded once (:50) and disposed in `Dispose` (:119). The detector's double dispose via the factory registration (DependencyInjection.cs:52) is harmless because `Dispose` is idempotent and locked (YoloObjectDetector.cs:101-108).
- **Thread-safety:** the detector serialises `Yolo` behind `Lock`. The renderer is stateless apart from the read-only typeface. Metrics use a lock for the numbers and a `Volatile` snapshot copied with `ToArray()`. Home polls with `InvokeAsync(StateHasChanged)`. All correct.
- **Box normalisation / clamping:** correct. Coordinates are clamped to [0,1], `FitWithinUnit` guarantees `X+W ≤ 1` exactly (so `IsValid` holds for boxes touching the edge), and degenerate boxes are dropped. **Label placement:** above the box, falling back to inside, clamped horizontally and vertically. Correct. Labels can overlap each other or the Prüfzone label in crowded scenes (cosmetic, deferred).
- **Model path:** resolved against `AppContext.BaseDirectory`. `ValidateOnStart` reports the resolved path before any hosted service starts, and both Web and Tests link the model into their output. Correct.
- **export.py:** the opset, input and output checks are correct (`dims` handles symbolic dimensions, and the domain filter covers both `""` and `"ai.onnx"`). See #11 for hardening.

Positives:
- No pixel copies in the hot path: one pinned buffer feeds both YOLO and Skia, and the old BGRA→BGR copy and resize step is gone. Disposal ordering is commented where it matters.
- Infrastructure translates cleanly into Core: `Detection` holds normalized boxes, and no YoloDotNet or Skia types leak. `IOptionsMonitor` is used only in adapters, thresholds are hot-reloadable, and the validator reports the resolved model path.
- The per-frame error log is rate-limited, `OperationCanceledException` is excluded from the frame `catch`, and `PipelineMetrics` uses `TimeProvider` so it can be tested.

Verdict: **APPROVE** — no BLOCKER found. Fix the three MAJORs (#1 stream must survive detection failures, #2 label size for Meet, #3 licensing accuracy) before closing M3, and re-run the gates with the finished M3 tests.
